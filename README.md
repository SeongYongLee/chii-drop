# 치와치와

치이카와 캐릭터로 즐기는 낙하 퍼즐 대전 게임입니다.

싱글플레이의 **CPU 관전**에서 양쪽 캐릭터와 난이도를 선택해 자동 대전을 볼 수 있습니다.

이 게임은 비공식·비영리 팬게임입니다.

치이카와의 권리는 나가노 씨와 권리사에 있으며, 이 게임은 원작자나 권리사가 제작·운영하는 공식 게임이 아닙니다.

게임 규칙 설계는 뿌요뿌요를 참고했습니다. 이 게임은 SEGA가 제작·운영하는 공식 게임이 아닙니다.
